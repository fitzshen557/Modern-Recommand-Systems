# DFM — Modeling Delayed Feedback in Display Advertising

> Criteo | KDD 2014 | 延迟反馈建模的开山之作

---

## 一、背景与动机

在展示广告的 CVR（转化率）预估场景中，用户从点击到最终转化往往存在不确定的时间延迟——可能几分钟，也可能几周。这带来一个核心矛盾：

```
在线学习需要新鲜样本 vs 转化标签需要等待才能确定

如果等太久：样本失去时效性，模型跟不上线上分布变化
如果等太短：大量"实际会转化但还没转化"的样本被错误标记为负样本
             → 这些样本称为"假负样本"（Fake Negative）
```

DFM（Delayed Feedback Model）是第一个系统性建模这个问题的工作，核心思路：**既然转化时间存在延迟，那就把"延迟时间"本身当作一个变量，显式建模进模型里。**

Criteo 论文里的实证观察：公开数据集里 13% 的转化发生在点击后 2 周以上，说明延迟不是小概率事件，必须认真处理。

## 二、方法详解

### 2.1 核心变量定义（后续所有延迟反馈方法都沿用这套符号体系）

```
X : 输入特征
C : 该样本最终是否会转化（真实label，C=1表示最终会转化）
Y : 观测时该样本是否转化（观测label）
D : delay time，转化延迟时间 = 转化时间 - 点击时间
E : elapsed time，观测延迟时间 = 观测时间 - 点击时间

关键关系：
  Y=1  =>  C=1（观测到转化，则一定最终转化了）
  Y=0  <=>  C=0 或者 D>E（真的不转化，或者还没到转化的时候）
```

这套 X/C/Y/D/E 符号体系是整个延迟反馈研究领域的"通用语言"，后续 NoDeF、ES-DFM、DEFER、DEFUSE 全部基于它扩展。

### 2.2 转化概率建模（标准 LR/NN）

```
P(C=1|x) = sigmoid(w · x)     # 或用复杂 NN 代替线性模型
```

### 2.3 核心创新：延迟时间服从指数分布

DFM 假设转化延迟时间 D 服从指数分布：

```
p(D=d | C=1, x) = λ(x) · exp(-λ(x) · d)

其中 λ(x) = exp(w_d · x)   # 保证 λ(x) > 0，w_d 是可学习参数
```

指数分布的物理直觉：大部分转化发生在点击后不久，随时间推移转化概率指数递减——这符合大多数广告场景的经验观察。

### 2.4 联合似然函数

把"是否转化"和"何时转化"两个目标联合训练：

```
观测事实                         数学描述
Y=1  =>  C=1                    确定性
Y=0  <=>  C=0 或 E<D            不确定性（E<D表示还没到转化时刻）

负对数似然损失（简化表示）：
Loss = -Σ [ y_i · log(P(C=1|x_i)) + P(D=d_i|C=1,x_i) ]
         - Σ [ (1-y_i) · log( P(C=0|x_i) + P(C=1|x_i)·P(D>e_i|C=1,x_i) ) ]
```

第一项处理已观测到转化的样本（同时优化转化概率和延迟时间分布拟合），第二项处理未观测到转化的样本（可能真的不转化，也可能是还没到时间的假负样本）。

## 三、实验结果

DFM 在 Criteo 内部数据集上验证，相比不考虑延迟反馈的朴素 LR baseline：
- 显著降低了 CVR 预估的系统性低估问题
- 在延迟分布明显偏指数型的场景下效果最好

由于是2014年的早期工作，公开的量化对比数据有限，其历史价值更多在于**开创了这个研究方向和符号体系**，而非绝对指标领先。

## 四、懂哥点评

**核心贡献：** DFM 是这个领域的"祖师爷"，几乎所有后续工作（NoDeF、ES-DFM、DEFER、DEFUSE、TESLA等）都沿用它定义的 X/C/Y/D/E 框架。理解 DFM 是理解整个延迟反馈研究脉络的起点。

**核心缺陷（也是后续工作的改进方向）：**

1. **分布假设过强**：现实中转化延迟分布往往是多峰的、场景相关的（大促期间转化快、日常期间转化慢），单一指数分布假设过于简化 → NoDeF 用多核函数混合来解决

2. **没有样本回补机制**：一个假负样本后来真的转化了，DFM 不会把它重新以正样本的身份送回模型训练——**这是最大的实践缺陷**。模型永远在"有偏"的训练分布上学习，即使转化最终发生了，模型也学不到这个正样本。这直接催生了后续基于重要性采样的整条方法路线（FNW/ES-DFM/DEFER/DEFUSE）

3. **联合优化的耦合问题**：转化概率预测和延迟时间预测联合训练，两个目标可能互相干扰，尤其在延迟分布本身就很复杂的场景下

**工业适用场景：** 如果你的业务延迟分布确实接近单峰指数分布（比如短转化周期的电商冲动消费），DFM 思路简单实现快，可以作为 baseline。但如果延迟分布复杂或者需要严格的无偏估计，应该直接上更现代的重要性采样方法（DEFER/DEFUSE/TESLA）。

**跟你天级归因体系的关联：** DFM 的"延迟时间作为特征/建模对象"这个思路本身值得借鉴——不管你用不用它的指数分布假设，把延迟时间信息利用起来始终是正确方向。
